# UI / UX Principles

## Rule 1

Three-second rule.

Users should understand their financial status
within three seconds.

---

## Rule 2

One screen.

The homepage should answer:

- How much can I safely spend?
- What needs attention?
- What should I do next?

---

## Rule 3

Color means action.

Green = Everything is normal

Yellow = Watch

Red = Action required

Blue = Information only

---

## Rule 4

Icons first.

Users should understand
without reading paragraphs.

---

## Rule 5

Never overload.

Every screen should have
one primary purpose.
